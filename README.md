# Tutoriels WEB

Il s'agit d'un regroupement de petits projets web qui ont pour but d'explorer les possibilités de développement liés à la réalisation de pages web interactives. Il s'agira généralement de pages simple permettant de tester différents outils et framework.

Ce dépôt n'est là que pour un but pédagogique et me permettre de renforcer mes compétences en développement.
