Deviner le nombre

Un petit jeu pour deviner un nombre aléatoire

Bienvenue dans le jeu "Devine le nombre" ! Le but de ce jeu est de deviner un nombre aléatoire compris entre 1 et 10000. Vous aurez un nombre limité d'essais pour trouver le bon nombre. Après chaque essai, vous recevrez un indice pour vous aider à vous rapprocher du nombre correct.

Pour commencer, cliquez sur le bouton ci-dessous pour générer un nouveau nombre aléatoire et lancer le jeu. Bonne chance !
