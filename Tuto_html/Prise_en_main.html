Toturiel de prise en main HTML

Ceci est une page HTML basique pour se refaire la main sur le développement de pages web. Le but derrière l'élaboration de cette page est de revoir les bases du développement web.
Au travers de cette page, nous allons revoir les fondamentaux de HTML, les balises et leur utilisation. On étudiera aussi l'utilisation du CSS permettant de modifier le style des pages, ainsi que l'utilisation de JavaScript pour ajouter des fonctionnalités interactives.

Qu'est-ce que HTML ?

HTML signifie « HyperText Markup Language » qu'on peut traduire par « langage de balises pour l'hypertexte ». Il est utilisé afin de créer et de représenter le contenu d'une page web et sa structure. D'autres technologies sont utilisées avec HTML pour décrire la présentation d'une page (CSS) et/ou ses fonctionnalités interactives (JavaScript). (Source : MDN Web Docs)

Les balises

Voici une liste des balises HTML les plus courantes :

  • <html> : Élément racine d'une page HTML
  • <head> : Les métadonnées de la page
  • <title> : Titre de la page
  • <body> : Contenu de la page
  • <h1> à <h6> : Titres
  • <p> : Paragraphe
  • <a> : Lien
  • <img> : Image
  • <ul> : Liste non ordonnée
  • <ol> : Liste ordonnée
  • <li> : Élément de liste

Le CSS

Le CSS (Cascading Style Sheets) est un langage de style utilisé pour décrire la présentation d'un document HTML. Il permet de modifier l'apparence des éléments HTML, tels que les couleurs, les polices, les marges, les bordures, etc. Le CSS peut être intégré directement dans le fichier HTML ou être lié à un fichier externe.

Gestion d'évènements

La gestion d'évènements se fait via l'utilisation de JavaScript afin de rendre les pages web interactives. Pour faire appel à Javascript, il existe deux méthodes :

  • Soit en rédigeant le code dans un fichier .js qui sera ensuite appelé dans le fichier HTML via l'ajout d'une balise <script>.
  • Soit en rédigeant le code directement dans la balise <script> du fichier HTML.
